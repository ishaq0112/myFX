Getting started

              
The MyFX API is a REST API that returns JSON. All endpoints live under the base URL below and require an API key.


              

                
Base URLhttps://api.myfx.dev

                
Auth headerX-API-Key: myfx_live_… on every request

              


              
Create a key on the API Keys page, then send it in the X-API-Key header. Here's your first request:


              

                

                  

                    
                    
                    
                  

                  
                


curl "https://api.myfx.dev/v1/latest?base=USD" \
  -H "X-API-Key: myfx_live_xxxxxxxx"


const res = await fetch("https://api.myfx.dev/v1/latest?base=USD", {
  headers: { "X-API-Key": "myfx_live_xxxxxxxx" }
});
const data = await res.json();
console.log(data.rates.EUR);


import requests

res = requests.get(
    "https://api.myfx.dev/v1/latest",
    params={"base": "USD"},
    headers={"X-API-Key": "myfx_live_xxxxxxxx"},
)
print(res.json()["rates"]["EUR"])

              

            


            
            

              
Endpoints

              
Three read-only endpoints. All return 200 with a JSON body on success.


              
              

                
GET/v1/latest

                
Returns every supported currency's rate relative to your chosen base currency.

                

                  
basestringBase currency (ISO 4217). Optional, defaults to USD.

                

                

                  

                    

                      
                      
                      
                    

                    
                  


curl "https://api.myfx.dev/v1/latest?base=USD" \
  -H "X-API-Key: myfx_live_xxxxxxxx"


const res = await fetch("https://api.myfx.dev/v1/latest?base=USD", {
  headers: { "X-API-Key": "myfx_live_xxxxxxxx" }
});
const data = await res.json();


import requests

res = requests.get(
    "https://api.myfx.dev/v1/latest",
    params={"base": "USD"},
    headers={"X-API-Key": "myfx_live_xxxxxxxx"},
)

                

                
Response

                


{
  "provider": "MyFX",
  "source": "European Central Bank + National Bank of Poland",
  "base": "USD",
  "date": "2026-09-01",
  "count": 149,
  "rates": {
    "EUR": 0.9231,
    "GBP": 0.7845,
    "INR": 88.42,
    "JPY": 147.83
    // …145 more
  }
}

                

              


              
              

                
GET/v1/convert

                
Converts an amount from one currency to another using the latest rate.

                

                  
fromstringSource currency. Optional, defaults to USD.

                  
tostringRequired. Target currency.

                  
amountnumberAmount to convert. Optional, defaults to 1.

                

                

                  

                    

                      
                      
                      
                    

                    
                  


curl "https://api.myfx.dev/v1/convert?from=USD&to=INR&amount=100" \
  -H "X-API-Key: myfx_live_xxxxxxxx"


const url = "https://api.myfx.dev/v1/convert?from=USD&to=INR&amount=100";
const res = await fetch(url, {
  headers: { "X-API-Key": "myfx_live_xxxxxxxx" }
});
const data = await res.json();


import requests

res = requests.get(
    "https://api.myfx.dev/v1/convert",
    params={"from": "USD", "to": "INR", "amount": 100},
    headers={"X-API-Key": "myfx_live_xxxxxxxx"},
)

                

                
Response

                


{
  "provider": "MyFX",
  "source": "European Central Bank + National Bank of Poland",
  "from": "USD",
  "to": "INR",
  "amount": 100,
  "rate": 88.42,
  "result": 8842,
  "date": "2026-09-01"
}

No parameters.

  -H "X-API-Key: myfx_live_xxxxxxxx"


const res = await fetch("https://api.myfx.dev/v1/currencies", {
  headers: { "X-API-Key": "myfx_live_xxxxxxxx" }
});
const data = await res.json();


import requests

res = requests.get(
    "https://api.myfx.dev/v1/currencies",
    headers={"X-API-Key": "myfx_live_xxxxxxxx"},
)

                

                
Response

                


{
  "provider": "MyFX",
  "count": 149,
  "sources": ["European Central Bank", "National Bank of Poland"],
  "currencies": [
    { "code": "AED", "name": "UAE Dirham" },
    { "code": "AFN", "name": "Afghan Afghani" }
    // …147 more
  ]

Response fields

              
What each field in a response means.

              

                

                  
FieldTypeDescription

                  
                    
providerstringThe API brand serving the data (MyFX).

                    
source / sourcesstring / arrayUpstream feeds the rates were built from (ECB, NBP).

                    
basestringBase currency the returned rates are relative to.

                    
datestringPublication date of the rates (YYYY-MM-DD).

                    
countnumberNumber of currencies returned.

                    
ratesobjectMap of currency code to rate against base.

                    
from / tostringSource and target currency (convert only).

                    
ratenumberExchange rate applied, to per from (convert only).

                    
resultnumberConverted amount, rounded to 2 decimals (convert only).

                  
                

              

            


            
            

              
Errors

              
Errors return the matching HTTP status and a JSON body with an error message.

              

                

                  
StatusMeaningWhen it happens

                  
                    
400Bad RequestUnknown currency code, missing to, or a non-numeric amount.

                    
401UnauthorizedMissing or invalid X-API-Key header.

                    
429Too Many RequestsYou've reached your plan's monthly request quota.

                  
                

              

              
Error shape

              


{
  "provider": "MyFX",
  "error": "Unsupported currency: \"XYZ\"."
}

              

            


            
            

              
Rate limits

              
Each plan includes a monthly request quota. Once reached, further requests return 429 until the next cycle.

Free2,500 / month5 req / minDaily

                    
Pro100,000 / month120 req / minHourly

                    
Business500,000 / month400 req / minReal-time

                    
Enterprise1M+ / monthCustomReal-time

                  
                

              

              
There is no overage billing. Requests are rejected at the quota rather than charged, so you never get a surprise bill.

            


            
            

              
Data & freshness

              
Where the numbers come from and how current they are.

              
    
                
  • Sources: European Central Bank (ECB) and the National Bank of Poland (NBP), merged into a single EUR-based reference set.
    • 
                
  • Coverage: 149 currencies.
    • 
                
  • Freshness: updated once daily on banking days, when the central banks publish.
    • 
                
  • Cross-rates: any base currency is derived from the EUR reference rates.
    • 
              

              
These are mid-market reference rates, not executable trading rates. Use them for display, analytics, and estimation, not to settle live trades.
